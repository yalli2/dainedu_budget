# 다인에듀 재무 대시보드 (dainedu_budget)

다인에듀(다인원격평생교육직업학원)의 월별 수입·지출을 정리하고 월별·분기별·반기별·연간 통계를 보는 대시보드입니다.

## 데이터 보관 방식
- 이 저장소에는 **화면(코드)만** 있습니다. 재무 데이터는 올라가지 않습니다.
- 입력한 데이터는 사이트를 연 **브라우저 안(localStorage)에만** 저장됩니다.
- 매달 입력 후 **데이터 관리 → 백업 파일 저장**으로 `.json` 파일을 받아 안전한 곳(구글 드라이브 등)에 보관하세요.
- 다른 기기에서는 백업 파일을 **불러오기** 하면 그대로 이어서 쓸 수 있습니다.

## 화면 구성
| 탭 | 내용 |
|---|---|
| 📊 대시보드 | 기간(월/분기/반기/연) 선택 → 총수입·총지출·순이익·미수금·예상수입·잔고, 추이 차트, 분류별 구성, 수입원 순위, 미수금/미납 체크 |
| ✏️ 월별 입력 | 수입(입금완료/대기/예상), 지출(청구액/실지출, 사업장 구분), 통장 잔고, 메모 · 지난달 항목 복사 |
| 📑 재무제표 | 손익 계산서(월별·분기별·반기별·전체·연도별), CSV(엑셀) 저장, 인쇄/PDF |
| 💾 데이터 관리 | 백업 저장/불러오기, 전체 내역 CSV, 수입·지출 분류 관리 |

## 계산 기준
- **수입** = 입금완료 + 입금대기 (확정 수입). '예상수입 포함'을 켜면 예상분도 더합니다.
- **지출** = 실지출 금액 (청구액과 다르면 실지출 기준).
- **순이익** = 수입 − 지출, **이익률** = 순이익 ÷ 수입.
- **잔고** = 해당 기간 중 마지막으로 잔고를 기록한 달의 계좌 합계.
